# History

How the game was built so far. The prototype phase happened in a Claude chat (claude.ai), where the game was
published as a private artifact for testing on the iPad. That chat history does not carry over to Claude Code,
so this file is the summary.

## Session 1 — 15–16 Nov 2026 (Claude chat)

- Started from the question "can I build a 2D arcade game for iPad with Claude Code?" → pivoted to a business-building game.
- Chose: web game, turn-based, coffee shop theme first, goal €1M company value in 5 years.
- **v1**: cart → kiosk → café → flagship; one price per cup, baristas, three bean qualities, marketing,
  machines, bank loan, random events, advisor tips, autosave.
  First balance pass: margins were far too fat (won in ~1 year) → raised rent/wages, goal from €500k to €1M.
- Sam's feedback: news came a week late → predictable events are now **forecast** one week ahead.
- Sam's idea: understand where customers come from → **POS** and **marketing analytics** systems, customer source breakdown
  (passers-by, word of mouth, marketing, social media) and marketing return.
- Sam **won v1 in week 142** (year 3). Observations: the late game had nothing left to unlock; marketing at max awareness was wasted.
- Sam's ideas for v2 → built: **progress stats**, **menu with per-item prices and unlocks**, **staff roles** (barista, cashier, cleaner)
  with health inspections. Rebalanced with the simulator (see BALANCE.md).
- Added **dark mode**.
- v2 feels much harder; Sam is play-testing whether it's too hard.
- Moved the project to VS Code + Claude Code for the next phase (multiple businesses).
